# 🛡️ Cybersecurity Portfolio

Welcome to the repository for my personal Cybersecurity Portfolio! 

This is a modern, highly aesthetic, interactive web application built to showcase my skills in Ethical Hacking, Red Teaming, Vulnerability Assessment, and my achievements in Capture The Flag (CTF) competitions.

## 🌟 Features

- **Aesthetic Glassmorphism UI:** Built with an interactive, animated "Aurora" background to give a sleek, premium hacker vibe.
- **Responsive Design:** Fully responsive layout ensuring it looks great on desktops, tablets, and mobile devices.
- **Categorized Arsenal:** Cleanly categorized skill tags displaying expertise in Core Concepts, Security Tools, Programming, Operating Systems, and Cloud Platforms.
- **CTF Operations Log:** Dedicated section highlighting achievements from TryHackMe (Top 6%), picoCTF, and competitive team CTFs.

## 🛠️ Technology Stack

- **Framework:** React.js (via Vite for lightning-fast builds)
- **Styling:** Tailwind CSS (Custom glassmorphism and deep slate aesthetic)
- **Animations:** Framer Motion (for smooth scroll reveals, bouncy hover states, and the Aurora background)
- **Icons:** Lucide React

## 🚀 Running Locally

If you want to spin this up on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KVS-04/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
